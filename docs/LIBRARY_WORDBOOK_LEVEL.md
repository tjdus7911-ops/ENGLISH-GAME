# 도서관 동화책 · 나만의 단어장 · 레벨 테스트

## 데이터 구조 (기존 저장소 확장, STORE_VERSION 3 → 4)

| 저장 위치 | 내용 |
|---|---|
| `learning.myWords[key]` | 나만의 단어장. key = 소문자 원형(lemma). `sources`(words·expression·book·grammar), `refs`, `context`, `savedOn`, `memorizedOn`, `srs`(기존 ReviewItem 형식) |
| `learning.books[bookId]` | `page`(마지막 쪽), `maxPage`(읽은 최대 쪽), `startedOn`, `readOn`(마지막 쪽 도달일), `quiz`(최고 기록) |
| `profile.levelTest` | 기존 필드 + `method`(test·manual·skip), `byArea`(영역별 정답), `history`(재응시·변경 이력) |
| `learning.savedWords` | 기존 '저장한 단어' 목록 유지. v4 마이그레이션 때 `myWords` 로 복사 (원본 삭제 안 함) |

마이그레이션은 기존 학습 기록·별·집 꾸미기·공간 확장 데이터를 그대로 두고 새 필드만 채웁니다 (`tests/logic/library-wordbook-level.test.ts`).

## 콘텐츠

- 동화책: `src/content/library/books-*.ts` (사람이 검수하기 쉬운 텍스트 형식, `parse.ts` 참고)
  - `original` = 이 앱을 위해 새로 쓴 이야기, `pd` = 저작권 보호기간이 끝난 원작(이솝 우화, 그림 형제, 안데르센 1837·1843, 오 헨리 1905, 영국·유럽 민화)을 **새 문장으로 다시 쓴** 이야기. 원작 번역문을 옮기지 않았습니다.
  - 모든 문장: 영어 · 한국어 번역 · 문장 구조 설명. 책마다 주요 단어와 이해도 문제(3~6개, 해설 포함).
- 단어 터치 사전: `src/lib/lexicon.ts` = 앱 영단어 DB + 동화책 주요 단어 + `src/content/common-lexicon.ts`(기능어·기초 어휘). 굴절형은 원형으로 찾고, 사전에 없는 단어는 뜻을 지어내지 않고 저장을 막습니다. 동화책·문법 예문·표현 대화·영단어 예문의 모든 단어가 사전에 있는지 테스트로 확인합니다.
- 레벨 테스트 문항 은행: `src/content/level-bank.ts` (영단어·문법·표현·독해 × A1~C1 × 5문항 = 100문항).

## 기능 규칙

- **음성**: 브라우저 음성 합성(speechSynthesis), 영어 음성 우선 선택. API가 없거나 영어 음성이 없으면 안내 문구를 보여 주고 재생 버튼을 숨깁니다(읽기·단어 뜻은 계속 사용 가능).
- **듣기 모드**: 문장을 차례대로 읽고 현재 문장을 강조, 자동 넘김을 켜면 다음 쪽으로 이어서 재생. 끄면 쪽 끝에서 멈춤(수동 모드). 0.75/1/1.25배속, 한 문장 반복, 이 쪽 전체 듣기.
- **SRS**: 기존 간격(당일·1·3·7·14·30일)과 `applyReviewResult` 를 그대로 사용. 정답률 80% 이상이면 단계 상승(같은 날 중복 상승 없음), 50% 미만이면 내일 다시 + 반복 오답은 '자주 틀림'으로 큐 맨 앞.
- **상태**: 새로 저장(복습 기록 없음) · 학습 중 · 복습 필요(복습일 도래) · 암기 완료(14일 단계 도달 또는 직접 표시).
- **적응형 테스트**: A2에서 시작해 같은 레벨 2연속 정답이면 한 단계 위, 오답이면 한 단계 아래. 영역을 번갈아 24문항. 2문항 이상 푼 레벨 중 정답률 60% 이상인 가장 높은 레벨을 추정(공인 결과 아님 표시).
- **추천**: 학습 레벨 중심 + 다음 레벨 1개(‘도전’). 날짜별로 고정, 이미 학습·저장한 항목 제외. 해당 레벨 콘텐츠가 없으면 아래 레벨로 대체하고 그 사실을 표시.
