## 2. 캐릭터 진화 판정

기존 시트 하단 행은 **체형이 같고 장식만 추가된 변형**으로 판단했습니다 (모시 꽃 화관, 플립 연잎 모자, 루미 반딧불, 코비 작은 가방, 위스크 반짝이, 스텔라 별자리 선). 코비·위스크는 차이가 특히 작습니다.

- 기존 상단 = 기본형 (idle · walk · wave) — 그대로 사용
- 기존 하단 = "성장 변형" — 진화 연출의 중간 프레임으로 재사용
- 신규 진화형 6종 = 체형·특징 자체가 성장 (모시: 새싹→꽃나무·고사리 / 플립: 물결 볏·물 망토 / 루미: 큰 발광 갓·아기버섯 / 코비: 큰 솔방울 갑옷·도토리 투구 / 위스크: 구름 꼬리 3개·구름 날개·초승달 / 스텔라: 별자리 뿔·성운 갈기). 각 8포즈 = 대기·걷기·인사·기쁨·잠·공부·앉기·진화.
- 신규 기본형 행동 6종 = 기존에 없던 기쁨·잠·공부·앉기 4포즈만.

## 3. 시안 제작 방식 (실제 배치 기준)

마을·집·정원 상태 시안은 손으로 합성하지 않고 **실제 React 장면 컴포넌트**(VillageScene · HouseScene · GardenScene)를 개발 전용 하네스(`harness.html`, 프로덕션 빌드 제외)로 렌더해 Playwright 로 캡처했습니다. 따라서 시안의 가구 위치·크기 = `src/game/layout.ts` 좌표 = 앱 화면입니다.

이 과정에서 발견·수정한 문제:
- 캐릭터 포즈마다 트림 크기가 달라 idle↔walk 전환 시 크기가 출렁임 → 캐릭터별 공통 캔버스로 정규화 (`normalize_characters`)
- 휴대폰 폭에서 꾸미기 슬롯 라벨이 서로 겹침 → 선택된 슬롯만 라벨 표시 + 하단 시트에 슬롯 칩 목록 (Figma 04 반영, 앱 SlotMarker 는 원래 아이콘만 표시)
